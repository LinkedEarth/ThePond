Tracing a Workflow in a Notebook

A scientific notebook brings together the question, data, methodological choices, code, and results of an investigation. In this LiLyPad, you will trace how those pieces connect.

Choose a scenario

Choose one of the four scenarios below. You do not need to run or edit the code. Read the notebook and use its narrative, code, and displayed results to reconstruct the workflow.

  1. Select a passage or code in the notebook on the left.
  2. Choose Data / output, Analysis, or Parameter, give the component a meaningful name, and select Create box.
  3. Drag the box by its header to arrange it on the canvas. You can also focus a header and use the arrow keys to move it.
  4. Draw an arrow by selecting Connect on the source box, then Connect on the destination box. Arrows show where data and parameters are used and what an analysis produces.
  5. Select Source on a box to return to the passage that supports it.

A workflow component may be described in several places. Choose a passage that helps you explain its role; you do not need a box for every sentence or line of code. Intermediate results count as data even when they are held in memory rather than saved to a file.

Use Download my work to save your boxes, source quotations, and arrows. Restore download loads that file back into the same scenario. Progress is also saved in this browser when available; use the download to keep a portable copy. Switching scenario tabs preserves each scenario’s work separately.

Tip

The reference sketch is collapsed at the end of each notebook. Try tracing the workflow yourself before opening Show the reference workflow. Your wording and layout can differ from the reference.

Reflect on your workflow

Compare your reconstruction with the reference sketch:

  • Can you trace an intermediate dataset from the step that creates it to the step that uses it?
  • Which parameters affect the final result, and where are their values documented?
  • Did the notebook specify a choice that was not explicit in the original sketch?
