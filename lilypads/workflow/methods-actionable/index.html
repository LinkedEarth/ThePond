Are Methods Actionable?

Can you reproduce this result?

NoteInstructions

Chances are you have come across results in scientific publications, posters or talks, and wondered: “How did they get here?”. Supposedly that is what the Methods section explains, but that information is not always actionable.

Each scenario below starts from an excerpt of a methods section (a real one for Correlations, a fictitious one for Spectral Analysis). The goal of the exercise is to determine whether the provided instructions are sufficient to reproduce the results shown in Figure 1. As you complete this exercise, take careful notes about what information is missing from the methods section that would help you reproduce the results.

Choose one scenario to complete.

  • Correlations
  • Spectral Analysis

Friis-Christensen & Lassen (1991) compared the length of the Sun’s activity cycle with Northern Hemisphere temperature (Figure 1) and concluded:

“There is a close association between the two curves in the up-going trends from 1900 to 1940 and since 1970, as well as in the important decrease from 1945 to 1970.”

Reproducing the analysis

The paper’s methods section leaves three steps open to interpretation. Try different readings of each and see whether the claim still holds, especially since 1970 (shaded). Some of these gaps matter, and others don’t.

If you want to go further (correlations, statistical significance, data up to the present), try the Deep End version of this exercise.

Imagine the following line in an article, without further description: We examined interannual variability in the El Niño Southern Oscillation (ENSO) using spectral analysis. Results of this analysis are shown in Figure 1.

Reproducing the analysis

Use the information provided in this cursory “Methods section” to reproduce Figure 1. Before you begin, know that while spectral analysis is a complex topic, you do not need to know anything about it for the purposes of this exercise. You can treat it as “black box” involving many possible decisions, and the point of the exercise is to show just how ambiguous the deceptively simple the phrase “using spectral analysis” can be.

      const url =
        URL.createObjectURL(blob);


      const link =
        document.createElement("a");


      link.href =
        url;


      link.download =
        "workflow-reproduction-notes.txt";


      document.body.appendChild(link);

      link.click();

      link.remove();


      URL.revokeObjectURL(url);

    });


  // --------------------------------------------------
  // Control listeners
  // --------------------------------------------------

  dataset.addEventListener(
    "change",
    updateSummary
  );


  detrend.addEventListener(
    "change",
    updateSummary
  );


  regridding.addEventListener(
    "change",
    updateSpectralOptions
  );


  spectral.addEventListener(
    "change",
    updateSummary
  );


  significance.addEventListener(
    "change",
    updateSummary
  );


  // --------------------------------------------------
  // Initial state
  // --------------------------------------------------

  updateSpectralOptions();

  updateSummary();


  return root;
}
